# v0 context pack

The app is built with Next.js 16 (App Router), React 19 and TypeScript, using shadcn/ui components (Radix base, listed in `shadcn-components.md`), Tailwind CSS 4, lucide-react icons and Recharts. It uses a dark theme only, with an emerald brand colour (`--color-brand`, emerald-400 `#34d399`) and the Sora font. Tailwind 4 has no `tailwind.config` file: the theme tokens (`bg-card`, `text-fg-primary`, `bg-brand`, `border-border-subtle`…) live in `globals.css`, and `postcss.config.mjs` is the only Tailwind setup file. **Rule for generated components:** take all data through props (see the `PurchaseCostsState` types in `purchase-costs.tsx`) and contain no calculation logic. Stamp duty, LMI, fees and totals arrive already calculated. Only small display derivations, such as a percentage of the price, are allowed in the view.
